# Product Category Revenue Analysis

## Description
This project analyzes revenue by product category using Excel, SQL, and Power BI. It helps businesses understand sales patterns and make data-driven decisions.

## Tools & Technologies
- Microsoft Excel
- SQL (MySQL/PostgreSQL)
- Power BI

## Data Source
- Sample retail sales dataset (included in this repository)

## Features
- Analyze revenue by product category
- Trend analysis over time
- Generate visualizations using Excel and Power BI
- Extract and manipulate data using SQL queries

## How to Use
1. Open Excel files included in the repository to explore the analysis.
2. Run SQL queries using your preferred database (MySQL/PostgreSQL).
3. Open Power BI dashboard:  
   - Open `PowerBI/RevenueDashboard.pbix` in Power BI Desktop
